# Поток

Демоверсия Instagram CRM на **React + TypeScript + Vite** для проверки UI/UX на компьютере и телефоне. Исходный макет `index (1).html` сохранён как справочный файл и не входит в сборку.

## Как работает демо

При открытии приложения появляются 20 примеров контактов на всех этапах воронки. Можно создавать, редактировать и удалять контакты, менять этапы, заметки, суммы, продукты и приоритет. Поиск, фильтры, сортировка, история, аналитика и экспорт CSV работают с текущими данными.

**Изменения хранятся только в памяти до перезагрузки страницы.** Переходы между разделами сохраняют их. Обновление страницы или повторное открытие приложения возвращает исходные примеры; у каждой вкладки свои данные. Для сохранения результата проверки скачайте CSV перед перезагрузкой.

Сервер, база данных, API, подключение Instagram и автоматизации удалены. Значения «Instagram» и «ManyChat» в карточках — только метки источников для проверки интерфейса и аналитики. Контакты добавляются вручную. Приложение не использует localStorage/sessionStorage и не читает старые сохранения.

Исходные показатели: 15 лидов в работе, 3 оплаты, 2 отказа, выручка 78 000 $, потенциал 365 000 $ и конверсия 15%. Показатели пересчитываются при изменении карточек.

## Локальный запуск

Нужен Node.js 22.18+ (рекомендуется 24 LTS).

```sh
npm ci
npm run dev
```

Откройте **http://localhost:5173**. Для проверки с телефона в той же Wi-Fi сети используйте адрес Network, который выводит Vite.

```sh
npm run build       # TypeScript + production-сборка в dist/
npm run preview     # просмотр production-сборки
npm test            # правила CRM, CSV и данные в памяти
npm run test:e2e    # сборка и браузерные тесты production-версии
```

Браузерные тесты проверяют desktop и мобильную эмуляцию через установленный Google Chrome. Если Chrome отсутствует, установите Chromium командой `npx playwright install chromium` и удалите `channel: 'chrome'` из `playwright.config.ts`.

## Публикация на Vercel

В корне есть `vercel.json` с настройками статической Vite-сборки. Подключите репозиторий к Vercel и выберите:

- **Root Directory:** корень этого проекта.
- **Framework Preset:** Vite.
- **Build Command:** `npm run build`.
- **Output Directory:** `dist`.
- **Environment Variables:** не нужны.

Затем нажмите **Deploy**. Сборка содержит HTML, CSS, JavaScript, шрифты и иконки; серверные функции и внешняя база не требуются. См. [документацию Vercel для Vite](https://vercel.com/docs/frameworks/frontend/vite).

Навигация использует адреса `/#overview`, `/#pipeline`, `/#leads`, `/#analytics`, поэтому дополнительные rewrites не нужны. Иконки и web manifest позволяют добавить ярлык на главный экран. Полного офлайн-кэширования нет.

## Структура

```text
src/
  App.tsx                 оболочка, навигация, уведомления
  components/             воронка, карточки, форма, аналитика
  hooks/useCrm.ts          состояние текущей сессии
  lib/domain.ts           типы, схемы данных, фильтры и правила CRM
  lib/export.ts           экспорт CSV
  data/seed.ts            20 демоконтактов
  services/leads.ts       данные только в памяти
  styles.css              desktop, tablet, mobile, safe-area
public/                   иконки и web manifest
tests/                    модульные и браузерные сценарии
vercel.json               статическая сборка для Vercel
```
